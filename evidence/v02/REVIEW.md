# V0.2 空间关系迭代 · 2026-10-17

本轮在 fanxiaofang/landscap-labV2 当前工程继续推进。React、TypeScript、Three.js 和正交投影语言保留；未新建项目，未加入云海、四季、天气或树木装饰系统。工程检查通过，视觉构图等待作者审阅。

## 位置锁定问题与处理

V0.1 把 10 组资产作为一张固定 SVG 叠加，主屋、拖拉机、桥的原始屏幕坐标间接规定了草甸和农田的边界。草甸后缘过于平直，较近且较大的山群贴着后缘出现，地形数值虽有高差，画面仍读成前景平板与后方山墙。

V0.2 保留不可变的原始资产快照，在外层逐组应用布局变换。每组定义地形坐标、源图接地参考点和等比缩放，目标高程取自连续地表。先确定生活台地、左侧农业坡肩、中央谷口和远处山脊，再让资产适配这些位置。原始截图只作为来源对照，不再作为最终布局约束。

主屋和主要设施没有重新绘制或替换成低模资产。预览、校准视图与 PNG 导出共用布局数据。

## 检查证据

- `npm run check:geometry`：15 项断言通过。
- 主屋支撑范围高程约 197.84–201.47，最大坡度 1.79°；中心高程 +200。
- 田块最大坡度 9.32°；相对实际地表网格间隔 0.735–0.865，避免深度冲突。
- 连接路径采样 501 点，从 +200 下行到 +150.16；最大坡度 7.46°，局部温和上行不超过 0.96°。
- 路径检查允许草甸温和起伏，检查整体下降和局部坡度，不再要求每个采样点机械地单调下降。
- 连续性检查使用两侧外推极限，避免把正常坡面上两点的高度差误判为接缝；最大极限差约 2.6×10⁻¹²。
- 8 个山群单元均低于主屋草甸，最高观景脊为 −445；实际地面轴仍为 ±15.806°，相机仰角 16.445°。
- 网格无非有限顶点、退化面、倒置法线或非流形边。
- 浏览器检查包含 1200×800 实际导出、确定性、校准/线框、四种视口、参考切换、原始 SVG 和重排后 10 组资产的变换与可见性。
- 原始 SVG 与仓库 HEAD 一致，重排后的源子树完全一致；主屋 scale=1。历史 provenance 的原始校验和与仓库中既有快照不一致，V0.2 没有修改该来源记录，改以仓库基线和子树一致性验证保留情况。

完整数据见 `evidence/geometry-report.json`、`evidence/browser-report.json`、`evidence/asset-placement.json`。浏览器使用 Chromium / SwiftShader 软件 WebGL，不是硬件性能测评。检查通过不代表美术验收通过。

## 尚未解决

1. 山体轮廓和坡面仍偏简化，部分远丘较平，谷底的大色面还缺少更自然的层次。当前有更多留白，但未达到秋季目标图的山群节奏。
2. 草甸已有高程起伏与轮廓变化，前缘的大块面仍偏均匀；后续可以继续调整宽色块与坡肩，当前没有用草纹理遮掩问题。
3. SVG 使用组级接地参考点。桥墩、建筑多个脚点、树与羊群组内各个物件，尚未进行逐点碰撞或独立坡面适配。
4. 固定浅俯角与概念图的镜头存在差异。保持正式投影兼容后，高处俯瞰感仍有进一步调整空间。
5. 正式 React 交互、房间切换、动态视差、SVG 与地形完整遮挡尚未接入。云海、季节植被与天气均未实现。

本轮提交的是可运行、可对照、可继续修改的 V0.2 构图，不宣称已经完成最终美术验收。
