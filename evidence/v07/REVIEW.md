## 哪些地貌重新设计了

- **高草甸**：将原来贯穿画面的单向后缘改为两侧不等长坡肩、局部凹入谷口和中央生活区前缘；加入宽缓隆起与洼地，只保留主生活区的小范围稳定高程。移除后缘深绿色硬带和平行装饰色带，颜色随坡面与区域平缓过渡。
- **中景山群**：删除统一缩放的放置表，逐组重写主峰、次峰、低鞍和下降支脊。中央群保留长西肩与扇形山脚，右近群用较高主峰、偏置低次峰和两条向谷底延伸的支脊组织体块，中西群降低主峰以保持层级。
- **极远山脉**：西岭和东岭重新设计为较低轮廓并错开深度；削弱原先连续高紫灰山墙的压迫，扩大远方天空与低谷视线。
- **接合方式**：草甸、谷地和山群从独立叠网格改为一张共享顶点与法线的连续地表。支脊合并在谷底逐渐衰减，避免凸边；山脊包络平滑处理采样交界，减少折痕。

## 为什么更能表达高地俯瞰

目标正交相机、仰角和投影均未改变。草甸谷口的凹入打断原来一直线的斜坡边缘，给前景平台与下方盆地提供不同深度的参照；宽肩和下降支脊把峰顶连接到更低的谷底，主次峰在世界高程上均低于生活区。远山降低后，天空留白扩大，画面不再被原先的高墙封住。

自由斜视、俯视与侧视可以确认这些形状属于真实地表，而非单张目标截图的轮廓贴片。辅助 [俯视](checks/top.png) 和 [侧视](checks/side.png) 图也已保存；侧视能看到有限地表的外边界，这不是内部断层或封闭实体山体。

这些调整提供了俯瞰关系的结构基础，**并不表示目前的俯瞰感和构图已经达到秋季定稿**。

## 实际截图仍暴露的问题

1. **前景仍显简化**：草甸已有局部谷口和起伏，但大片绿色区域的高程层次在低仰角目标视角中仍偏弱；目前较圆的边界是否过于柔缓，需要人工判断。不能仅凭自由视角有起伏就认定目标构图合格。
2. **中景轮廓分离度不足**：中央与右近山群在无云目标视角下仍有重叠，部分支脊和山脚被前景挡住。当前主峰、次峰与鞍部的节奏尚未达到定稿中更有变化的群山关系；仍须审阅尺度和间距。
3. **天空与远景比例变化明显**：远山墙已降低，但天空留白多于秋季定稿，远层更平缓。需要作者确认这种开阔程度是否符合目标，不以旧屏幕轮廓或数值占比强行验收。
4. **冻结云海仍偏厚**：现有连续云面覆盖多数低肩，远端边缘偏平，山体露出较少。没有为增加露峰而修改云团、透明度、材质或云面高度；本图不能证明未来云表现合格。
5. **资产适配未完成**：1200×800 Proxy 可以输出并保持投影契约，但历史田块、桥和辅助设施位置没有按新地形重新审阅。正式 SVG 未接入，接地、遮挡与可行走布局均不在本轮完成范围内。
6. 地形是有限高度场，外边界开放；极端平移/缩放能看见边界。当前没有封闭地层、地下体积或全世界无限地形。

## 工程验证

- `npm run build`：通过。Vite 仍提示 Three.js 包超过默认 500 kB 提示线，此项不影响本轮构建；未做无关打包优化。
- `npm run check:geometry`：通过。完整网格 157,473 顶点、313,564 三角形；1 个连通分量，0 内部孔洞，0 无效值、退化三角形或向下法线。只允许有限地表的外边界。
- 同一源码在 Node 与 Chromium 中的曲线浮点采样可能产生少量三角划分数量差异；浏览器内重复导出保持逐字节一致。本报告的拓扑统计来自 Node 实际生成网格。
- 1600×900 和 1200×800 目标投影最大测量误差约 `4.55e-13 px`。`projection.ts` 与 V0.6 哈希相同。
- `npm run test:visual`：通过。实际鼠标旋转、平移、缩放；三个自由预设；目标相机与材质精确恢复；云开关、线框、并排/叠图/擦拭及真实导出按钮均检查。
- V0.6 天空像素与当前原始画布、实际截图、两种目标导出一致且不透明。`drawSky()` 原样保留。
- 云海两份源码、环境调色板与云远端依赖的 `valleyHeight()` 均保留。浏览器错误 0，正式 SVG 请求 0。
- 390 / 768 / 1024 / 1600 宽度的双画框保持同尺度 16:9，无横向溢出；1200×800 Proxy 兼容图另存于 `checks/`。

证据：[geometry-report.json](geometry-report.json)、[browser-report.json](browser-report.json)。这些是工程结果，**不等于美术通过**。
