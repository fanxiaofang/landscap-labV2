# V0.4 构图验证记录

状态：**美术未验收。已完成本轮构图出图与检查，暂停等待作者审阅。**

## 基准与对照

秋季定稿图是唯一主要构图、占比与色彩基准，原图和项目副本经 SHA-256 核对一致。默认并排显示；透明叠图和擦拭共用 16:9 画框。原图 1672×941 与严格 16:9 有极小比例差，采用 contain 等比适配，不裁切或拉伸。

人工描出的定稿地貌外缘估算：天空约 23.2%，前景约 46.8%，谷地与山群所在中段约 30.0%。当前前景地形投影约 45.5%（见 JSON 实测值）。这是边界积分估算，不是像素分割，也不是自动通过条件。无云海画面与静态云海画面均独立保留。

## 本轮调整

- 前景从对称中央隆起改为左上向右下的连续高地边界。农田退到左侧与后缘，生活区仍由 Proxy 检查。
- 谷底改为带弯曲低槽与两侧坡肩的连续地表；抬起部分山脚过渡，减少单一灰色平底的读法。
- 保持八个山群单元，重新编排深度与尺度。中央与右侧采用非对称双峰、峰间鞍部、偏置支脊和不等长两侧坡面。细节仅为几何和色块。
- 静态云海为一个低起伏网格，通过真实深度遮挡山脚。没有时间输入、粒子、动画或自定义 Shader。
- 草甸明暗区域写入同一地表顶点颜色，消除重叠色块网格的深度冲突。

## 仍存在的视觉差距

1. **无云海时的山脚分离仍不足。** 谷地已有起伏，但部分近山底部仍叠成较重的体块。云层遮挡改善了预览读法，并没有证明底层山谷关系已全部成立。
2. **峰顶与支脊仍偏硬。** 双峰与鞍部已可辨识，但局部轮廓接近折纸；长坡肩的自然过渡和近、中、远山的尺度节奏仍需审阅。
3. **云海仍明显是占位层。** 连续留白与山脚遮挡可以判断，但边界过于平滑，缺少定稿图柔软、交错的云团层次。
4. **前景仍偏规整。** 大致占比和斜向边界接近定稿，田地长条和圆头边缘、草甸大色块仍显人工；不能因为占比接近就认为构图通过。
5. Proxy 只证明布局和体量可审阅，不包含正式资产的叙事密度、逐脚点接地和遮挡关系。

## 工程与停止点

`check:geometry` 检查网格、路径、贴地和两种画幅下投影矩阵；`test:visual` 检查真实渲染、默认秋季参考、等大画框、无云海恢复、确定性导出、叠图、擦拭、响应式及 1200×800 生成 SVG 契约。正式 SVG 请求必须为零。最终检查结果见对应 JSON，不以本节文字代替实际报告。

V0.3 的三个布局门槛已退为历史观察：主田屏幕位置低于主屋、主田完全入画、两田间隔大于固定像素。秋季定稿采用后退且左侧出画的农田，这些旧布局不能继续决定新构图。网格、坡度、连续性和贴地约束仍保留。

本轮在这些出图与差距说明处停止。美术是否通过由作者审阅，不继续接入正式 SVG，也不进入天气、季节或云海效果制作。
