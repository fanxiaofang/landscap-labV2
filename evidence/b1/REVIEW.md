## 选择曲线山体的理由

本轮使用 8 个可独立控制的闭合曲线 loft：3 个中景缓丘，最远层 1 个宽缓脊线，另外两层各 2 个错位山体。平面位置、起伏高度、前坡与后坡长度分别控制。调整某个山肩不会改变整片地貌；谷口由真实山体间距保留。没有规则圆锥、平面剪影或覆盖整幅画面的 Gaussian 高度底板。

一个局部谷底连接山脚与河道，不包含生活草甸或建筑支撑。山脚共用基础高度，余弦横截面在山脚回到水平切线；谷底高出数学山脚 2 个世界单位，将封闭底部和侧壁顶缘埋入地面，避免相切边缘闪烁。自由视角能看到有限谷底外边界与部分实体底部，这些是实验范围边界。

目标视角使用真实 Lambert 材质、方向光和半球补光。顶点色只做 ±2.6% 大尺度草色变化。可用“中性材质”和“反向侧光”检查：几何及顶点色不变时，背光侧与受光侧随光向互换。证据见 [左侧光](checks/neutral-light-left.png)、[右侧光](checks/neutral-light-right.png)。本轮不使用投射阴影、复杂水面或体积雾。

## 投影、合成与移动检查

保持旧 `projection.ts`：地面轴 ±15.806°，相机仰角约 16.445°，两者含义不同。一个目标正交相机渲染全部中远景；自由相机只作调试切换。SVG 叠加只在目标视角显示。

原始 `live-overview.svg` 文件未修改。适配器保留生活前景和原有农业／铁路资产，删除旧天空与旧山体。统一缩放 1.05、平移 (170,80) 后等比映射到目标画幅；左侧农田使用弯曲合成窗口，为河谷保留空间。此处用的是原应用的静态 SVG 快照；本仓库没有重建或替换原应用交互。

相机范围为 x ±100、y ±45、缩放 90%–118%。前景和中景共用配准变换；远山可选 5%／10%／16% 的平移视差。正交投影本身不会因距离自动产生这种平移视差，这里明确作为 2.5D 适配处理。

## 美术观察与未宣告通过的部分

| 项目 | 当前观察 | 归因 |
| --- | --- | --- |
| 真实体积 | 中景能读出坡肩、受光前坡和背光侧坡；反向侧光证明其来自曲面法线。 | 已建立实时光照与体积能力。 |
| 远山层次 | 目标视角可分辨至少两层，局部可读三层；位置和高度错开，谷口保留。 | 仍有较大、平滑的山肩，轮廓节奏是否足够自然需人工判断，属于造型问题。 |
| 河谷纵深 | Only 中河流形成连续通道，向谷口收窄；主段未被山体截断。 | 合成后近段按前景边界遮挡，河谷的可见长度比 Only 短。 |
| 草色与空间 | 有真实坡面明暗及距离色彩，避免仅靠平行色带表达层次。 | 材质仍很简化，不能宣称达到参考图的表面丰富度。该差距来自材质表达，不能靠堆树林或浓雾解决。 |
| SVG 融合 | 原前景保持比例，主屋与设施位于中景之前，目标平移缩放共享配准。 | 原 SVG 草甸及农田保留明显横向边界，左田块的弯曲裁口仍能辨认。是否足够自然是合成方面的待审问题。 |
| 接缝与范围 | 局部山脚和谷底使用同一基础高度；没有用前景隐藏检查视角。 | 模型是独立山体加局部谷底，不是无边界完整地形。自由侧视的外缘与底部不能解释为全场景连续表面。 |

相较旧 SVG，新增了可检查的坡面、背坡、空间遮挡与受光变化；相较 V0.8，山体轮廓与层间关系更易单独控制。**技术样板完成不等于美术验收通过**。若本轮仍未达到作者期待，优先审阅“山肩造型／轮廓节奏”和“SVG 交界”，其次是材质；投影契约已通过数值配准检查，不应继续通过改相机角度补救。

## 工程验证与后续适配能力

执行记录见 [geometry-report.json](geometry-report.json) 和 [browser-report.json](browser-report.json)。

- `npm run check:b1`：8 个山体闭合、有限数值、有效三角形、实体体积、前后坡、山脚高度，以及主河段射线检查；两个画幅共 54 个导航状态，最大配准误差约 1.4×10⁻¹² 像素。

- `npm run test:b1`：实际浏览器操作、导出、材质与侧光、前景资产保留、六个导航边界状态、响应式、兼容画幅和 V0.8 回退。报告记录实际结果，不替代人工美术审阅。

每个山体有独立定义、材质、法线和世界平面 UV，可继续增加季节调色、草甸纹理、沿坡林带或薄雾。原始前景交互在主应用中保留；真正接入时将其相机状态传入 B1 导航适配器即可。当前没有增加多相机运行时或复杂多通道合成。
