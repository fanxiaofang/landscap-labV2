## 与此前效果的变化

| 结构 | 此前 V0.7 | 本轮 V0.8 |
| --- | --- | --- |
| 生活区 | 高草甸与深谷之间落差大 | 宽平生活台地，右侧顺河谷退让 |
| 河谷 | 主要靠谷地留白和云占位 | 真正下切的连续河床、缓岸和蜿蜒水面 |
| 山体 | 窄脊、支脊及孤立露峰 | 横向宽丘体、低圆岭，全部并入同一地表 |
| 农田 | 旧横向长条田块在 benchmark 中隐藏 | 左侧主田块 + 两块更小延伸田，曲边、草地间隔和贴地垄线 |
| 雾 | 不透明厚云面 | 少量静态局部空气透视，不遮挡河床和山体 |
| 资产 | 当前阶段未集成 | 地形后依次验证 Proxy 和正式 SVG 对照 |

农田顺坡最远范围从主田块 d=502.82 延伸到 d=663.43，以主田块完整顺坡范围为基准增加 **21.9%**。这是新布局中主田与延伸田的相对范围，不声称旧田块面积增加了 21.9%。主田最大高程 199.68，低于主屋台地 200；两小田更低，面积逐渐缩小。

## 工程验证

- 连续地形：207,311 个顶点、412,800 个三角形，1 个连通分量，0 个内部孔洞，无退化面、无反向法线。
- 主屋支撑区几乎水平；木屋、设备区及羊圈的采样支撑差已记录。最大辅助区域支撑差约 4.95 场景单位，不通过挤压地形来迁就资产。
- 河床中心在被检查河段保持低于水面，样条连接无高度跳变。局部最大采样坡率约 0.78，主要缓岸区域更平缓；这不表示整条河岸都是水平地面。
- 两个画幅保留原 SVG 地面轴投影；数值误差低于 1e-7。
- 浏览器检查记录实际鼠标旋转 / 平移 / 缩放、相机及材质恢复、确定性导出、薄雾差异范围、四阶段按需加载和响应式。
- 原始 `live-assets.svg`、`projection.ts` 与旧版证据保持不变。

详见 [geometry-report.json](geometry-report.json) 与 [browser-report.json](browser-report.json)。

## 仍需人工判断的差距

- 这是地形和布局验收稿。地表着色、远山层次、田块细节仍比用户插画参考简化，未添加树群、田间小路网络、天空装饰等参考细节。
- 当前薄雾是顶点色的局部空气透视，无体积散射、风或动画。
- 正式 SVG 是二维目标视角叠加；自由视角隐藏这些资产。桥拱、建筑每个脚点和坡地遮挡尚不等于完整三维资产集成，不能据此宣称正式场景接地已全部验收。
- 地形是有限高度场，自由视角移到研究区域外仍可看到开放外边界。
