# V0.3 地形与占位构图 · 2026-10-17

本轮在 fanxiaofang/landscap-labV2 当前工程继续推进，保留 React、TypeScript、Three.js 和正式项目的正交投影语言。当前交付纯地形 → Proxy → SVG 对照三个模式，重点修正农田与主屋草甸的视觉高低关系。无云海、天气、四季或新增装饰。几何检查、浏览器检查和生产构建已通过；视觉构图等待作者审阅。

## 上轮问题与本轮策略

V0.2 已释放正式资产坐标，但左侧农业坡肩向远处突出，田块又全部位于主屋后方。固定浅俯角下，地形深度同样影响屏幕高低；即使农田的世界高程低于主屋，也会因距离更远而投影到主屋草甸上方。连续黄色田带进一步强化了独立山包的读法。

V0.3 收回西侧突出的坡肩，在中央保留宽阔的高地生活核心，两侧以浅洼和宽缓起伏过渡。农田改为三块形状、大小、朝向不同的局部地块：两块位于近侧西部浅洼，一块位于东侧草甸。田块之间保留草地，不再形成完整的横向农业平台。

地形先单独审阅；通用占位布局随后用于检查主屋体量与叙事关系；正式 SVG 最后作为可切换对照。地形参数不引用源资产边界，通用布局也不包含正式 SVG 的 ID、源接地点和缩放。这些源图细节只存在于资产适配模块。

## 投影关系检查

最终交付画幅固定为 1200×800，研究坐标的真实投影是：

~~~text
screenX = 600 + u
screenY = 530 - (77/272) * d - sqrt(1-(77/272)^2) * (h-200)
~~~

屏幕 y 越大越靠下。正式 Overview 原有的 0.66 缩放只描述源 SVG 的历史坐标映射，不再叠加到这里的 Three.js 画面投影。

当前主屋参考点 y=583.79，主田最上缘 y=604.29，主田在画面中至少低于该参考点约 20.50 px。两块左侧田之间的最小投影草地间隔约 38.99 px。主田完整入画。这些检查用于防止本轮明确问题回归；其他田块仍可以与草甸穿插，不要求所有田块都低于所有草甸区域。

数值只证明被采样的空间关系。高地感、开阔程度和主屋视觉地位仍需结合下面三个模式的截图审阅。

## 尚未解决

1. 谷底大色块和部分山脚仍偏简化；山群主次已调整，尚未达到最终目标图的全部空间层次。
2. 草甸外围有地势与轮廓变化，前缘色面仍较均匀。当前优先构图，不以草纹理或装饰填充。
3. 正式 SVG 仍使用组级接地参考点；桥墩、建筑多个脚点、羊群与树组内物件尚未逐点适配坡面。
4. Proxy 使用简化体块与占地轮廓，只检查体量和位置。正式 SVG 的完整深度遮挡、交互、房间切换和动态视差尚未接入。
5. 固定浅俯角与参考图的镜头存在差异，仍需结合真实投影判断俯瞰感。云海、天气、季节植被不在本轮范围。
