## 从写实摄影转换为项目简化插画

1. 先读结构：提取主次峰、山脊走向、坡肩、鞍部、遮挡、云谷与负空间，回到秋季定稿验证其比例和构图。
2. 简化轮廓与明暗：归纳大体块和少量连续明暗区域，保留不对称与尺度节奏，去除岩石纹理、碎裂细节、摄影锐化和逐三角形折纸式色块。
3. 转换颜色：遵循秋季定稿的暖色、空气层次和简化光影，不复制照片的蓝灰山色、强反差或写实材质。未来天气与时段可改变 tint，但不能仅用照片配色替代项目风格。
4. 转换云：保留覆盖、缺口、高度、软硬边与透射关系，用适合项目的简洁云形表达；不把照片贴进场景，也不要求所有情境共用同一厚重云毯。
5. 在目标正交视角检验美术，同时从自由视角检查三维结构；不可通过严重畸形几何硬匹配照片或定稿中的单张画面。

## 云形态的区别与天气关系

| 形态 | 覆盖与虚实 | 空间作用 |
| --- | --- | --- |
| 清透谷雾 | 稀疏、半透明、软边、不同高度的细雾带 | 露出山腰与树林，连接谷地，不能抹平地形 |
| 轻云海 | 大片柔和云面与局部断口并存，保留可读的山云边界 | 以缺口、露峰和前后关系增加纵深 |
| 厚云海／壮观云海 | 高覆盖、可有不透明厚云，有大尺度起伏和局部层次 | 强调高处俯瞰及山峰穿云，不能退化成平板 |
| 晴天天空云 | 疏密有别的白云与充足天空留白 | 强调天空开阔，与贴谷地的云海区分 |
| 阴天与夜间云 | 允许更厚、更暗，虚实取决于具体天气 | 组织阴天、夜间气氛，避免硬套秋季黄昏颜色 |

形态与天气预设分离，覆盖率、密度、厚度、透明度、高度和颜色由具体情境决定。低覆盖率不是所有季节与天气的永久限制。当前主要目标仍为秋季黄昏；清透参考用于补充未来天气表现，本轮不实现任何天气、季节或云渲染功能。
